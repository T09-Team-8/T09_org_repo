# KindDesign

KindDesign is a Copenhagen-based creative community bringing people together through curiosity, creativity, and connection.

This website introduces the KindDesign community, shares its story and event calendar, and gives visitors a look at community moments through the KindLife photo stories.

**Visit the website:** [KindDesign on GitHub Pages](https://t09-team-8.github.io/T09_org_repo/)

## Explore the website

- **Home** — Meet the community, browse event photos, and find KindDesign’s contact and social links.
- **About** — Learn about KindDesign’s story, values, community, and upcoming events.
- **Event Calendar** — Browse the event calendar and event information.
- **KindLife** — Explore community photo stories from Copenhagen, Berlin, and Buenos Aires.

## About the project

The website is built with [Astro](https://astro.build/) and uses reusable Astro components to present the pages and sections. The homepage features an animated hero background, community and event photography, and links to KindDesign’s Instagram, LinkedIn, and email.

The project is published on GitHub Pages from the main branch.

# KindDesign-webstedet

KindDesign er et kreativt fællesskab med base i København, der bringer mennesker sammen gennem nysgerrighed, kreativitet og fællesskab.

Webstedet præsenterer KindDesign-fællesskabet, fortæller dets historie, viser eventkalenderen og giver besøgende et indblik i fællesskabets øjeblikke gennem KindLife-billedfortællingerne.

**Besøg webstedet:** [KindDesign på GitHub Pages](https://t09-team-8.github.io/T09_org_repo/)

## Udforsk webstedet

- **Forside** — Mød fællesskabet, se eventbilleder, og find KindDesigns kontakt- og sociale links.
- **About** — Læs om KindDesigns historie, værdier, fællesskab og kommende events.
- **Eventkalender** — Se eventkalenderen og information om events.
- **KindLife** — Udforsk billedfortællinger fra fællesskabet i København, Berlin og Buenos Aires.

## Om projektet

Webstedet er bygget med [Astro](https://astro.build/) og genanvendelige Astro-komponenter. Forsiden har en animeret hero-baggrund, billeder fra fællesskabet og events samt links til KindDesigns Instagram, LinkedIn og e-mail.

Projektet udgives på GitHub Pages fra branchen main.
